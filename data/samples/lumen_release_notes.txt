Lumen Robotics - Firmware Release Notes
All products and figures in this file are fictional sample data.

Firmware 4.2.0 (released 2026-03-10)

New features
- Adaptive grip control for the LR-200 arm. The gripper now measures object slip and
  raises grip force by up to 15% before the object moves.
- Quiet mode for the LR-50 courier robot. Motor noise is limited to 42 dB between
  22:00 and 06:00 local time.
- The dashboard shows battery health as a percentage of the original capacity.

Fixes
- Fixed error E-4012 (joint encoder timeout) that could stop the LR-200 arm after
  long idle periods. The encoder is now polled every 50 ms instead of 200 ms.
- Fixed a navigation issue where the LR-50 stopped in front of glass doors.
- Fixed incorrect charging times shown for the CD-10 charging dock.

Known issues
- On LR-200 units built before 2025, adaptive grip may report error E-4107 during
  calibration. Workaround: run calibration twice, or install firmware 4.2.1.

Firmware 4.1.3 (released 2025-11-02)

Fixes
- Error E-3301 (battery temperature high) no longer appears when the room temperature
  is below 30 degrees Celsius.
- The LR-50 now resumes its route after an emergency stop is released.
- Improved Wi-Fi reconnection after a network outage. Robots reconnect within 20
  seconds instead of 2 minutes.

Firmware 4.1.0 (released 2025-08-18)

New features
- Remote diagnostics. Support staff can read error logs without visiting the site,
  if the customer enables remote access in Settings > Support.
- Scheduled maintenance reminders every 500 operating hours.

Error code reference

E-1001  Emergency stop pressed. Release the stop button to continue.
E-2204  Path blocked for more than 60 seconds. Clear the path or choose a new route.
E-3301  Battery temperature high. Move the robot to a cooler area and let it rest.
E-4012  Joint encoder timeout. Restart the arm; update to firmware 4.2.0 or later.
E-4107  Grip calibration failed. Run calibration again; see firmware 4.2.0 known issues.
E-5500  Charging dock not detected. Check that the CD-10 dock is powered and level.

Upgrade instructions

1. Make sure the robot is docked and the battery is above 40%.
2. Open the dashboard and go to Settings > Firmware.
3. Select the new version and press Install. The robot restarts automatically.
4. Do not undock the robot during the update. A typical update takes 8 minutes.
